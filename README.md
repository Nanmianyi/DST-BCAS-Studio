# BCAS Studio —— 饥荒联机版画质增强（V8 光影引擎）

**保留《饥荒》原本的手绘美学，然后把它调到最好。**

BCAS Studio 是《饥荒：联机版》打通全自定义后处理管线的画质增强 Mod。
通过官方 Mod 着色器接口接入实时渲染管线，锐化、墨线修复、电影调色、
辉光、海面波光、动态太阳光影全部在游戏内实时完成。

架构上把**调色 + 锐化 + 辉光合并进单个全分辨率 pass**，40+ 参数实时可调、
自动保存，性能开销与原版后处理相当甚至更省。

> 💡 **全开源项目**：源码、GLSL 着色器、构建工具链全部开放，遵循 MIT 协议。

## 核心技术原理

### 一、海面波光 —— 让水面第一次有"体感"

叠加在原版水体之上的一层程序化波光（不重写原版海洋渲染）：

- **散开式 caustics 光网**：两层 chained caustics 交叉；域扭曲把规则的六角网格
  揉成有机形状，再用大尺度 gate 成片抹除——光斑是散开的粼粼，而不是连成一片的网。
- **沙底质感**：低频沙丘明暗 + 稀疏细沙颗粒，混成半透明青调，读作清浅的沙底浅水。
- **浅 → 深丝滑过渡**：逐像素深度 = 离岸距离（引擎海水遮罩双环采样，昼夜无关）。
  浅滩金色通透；中海 caustics 沿风向各向异性拉长成长浪带、颜色转青；深海消退，
  交还原版青色与海浪。边界加噪声扰动，不生成硬线。
- **黄昏加速 · 潮汐感**：以环境光作太阳高度驱动时间缩放，太阳越低海面流动越快，
  沙面反光随之自然退去——模拟退潮后浅滩露沙的观感。
- **盐堆专属浅滩**：盐堆（saltstack）本被种在深海地块上；本 Mod 在其周围按簇生成
  不规则浅滩——盐堆终于立在沙堆上。

### 二、动态全局光影 —— 此前，饥荒没有光影

原版《饥荒：联机版》里**不存在方向性光影**。角色脚下只有一个圆形黑斑，夜晚只有光源照明，地上的树、建筑、草丛与黑夜之间没有任何光影关系。

- **世界空间太阳（日晷模型）**：根据世界相位（清晨/正午/傍晚/深夜）、满月周期与季节天气，由单一解析函数精确推导太阳矢量。
- **动态剪影投影系统**：角色、坐骑、树木、大型建筑挂载贴地剪影，与本体动画逐帧相位同步；砍伐、生长、骑乘即时变换形态；满月之夜倾泻冷色月光投影。
- **性能架构**：移动实体逐帧追踪、静态地物距离分层帧预算 + 错峰种子、夜晚与洞穴零开销门控；姿态更新量化、远处群体节流——满帧顺畅。
- **透云丁达尔光（God Rays）**：世界空间光斑配合云层开合状态机随机游走显隐，暖光抚过林间草木。

### 三、反卷积墨线修复（DECONV）

饥荒的美术资产经过图集合成和双线性采样后，手绘轮廓线的高频信息衰减严重。
经典反卷积依赖逐帧变化的点扩散函数估计，而这里的模糊来源是确定量——
图集合成与多级双线性缩放的低通损耗，核可参数化，问题从"估计"退化为"求解"：
定向边缘梯度检测提取主法向，套双边门控核反解弥散，不产生传统锐化的白边光晕。

### 四、双边自适应锐化（BCAS 算法）

继承作者开源的双边自适应锐化技术：
- YCoCg 色亮分离，锐化严控于亮度通道，绝不产生彩色噪斑；
- MAD4 局部活动量估算自适应调整双边核半径；
- AURA 双通道软限幅包络，锁死过冲溢出上限，画质无损提锐。

### 五、电影调色与辉光重构（单 pass 架构）

- **调色工作流**：曝光 EV → 白平衡光学色轮 → CDL 一级/二级 → ACES 胶片曲线高光滚落；
- **辉光**：软膝高光提取（膝钳到阈值，暗部永不被放大）→ 逐级 2x 盒式下采样的 mip
  金字塔（1/4 → 1/32，每级仅 4 抽头）→ 四级按权重画像合成（暖色随层级渐染、
  保色软肩压缩）。没有稀疏大步长采样，因此没有方块与斜向拖影；
- **单 pass 架构**：调色 + 锐化 + 辉光合成合并进一个全分辨率 pass，全屏渲染 2 次 → 1 次。
