[h2]≡ 动态全局光影（此前，饥荒没有光影）≡[/h2]
原版的世界没有太阳：角色脚下只有一个圆形黑斑，夜晚只有光源照明，
地上的树、建筑与黑夜之间没有任何光影关系。本 Mod 从零补上这一层——
[list]
[*][b]世界空间太阳（日晷模型）[/b]：单一解析式输出全局共享的影子长度、旋角、透明度与色温。清晨影子长而淡，正午收短变实，傍晚拉长，太阳第一次在饥荒里走完一天。
[*][b]剪影投影系统[/b]：角色与大型地物挂载贴地剪影，与本体动画逐帧相位同步；皮肤、骑乘（骑手+坐骑双剪影）、换装、树木生长阶段全部跟随；砍伐、燃烧、收割即时换形态。
[*][b]满月夜月光投影[/b]（染月光蓝），雨雪衰减，冬季收敛。
[*][b]性能架构[/b]：移动实体逐帧、静态实体距离分层帧预算 + 错峰种子、夜晚与洞穴零开销门控——满帧稳定。
[*][b]透云光束[/b]：光斑按 gap→in→hold→out 状态机模拟云层开合，随机落在玩家周边缓缓显隐，引擎光源给遮挡物勾暖亮边。
[*][b]太阳全局光[/b]：太阳屏幕位置驱动调色引擎的天光方向。
[/list]

[h2]≡ 反卷积墨线修复 ≡[/h2]
在饥荒内引入反卷积算法，对图集合成流程造成的贴图模糊做在线重置。
经典反卷积依赖点扩散函数估计，摄影场景的 PSF 逐帧变化、运动物体需要单独建模；
饥荒贴图的模糊来源则是确定量——图集合成与多级双线性缩放的低通损耗，
核可参数化为已知量，问题从估计退化为求解。
[list]
[*][b]实现[/b]：边缘法向检测 + 双边门控核 + 暗部穿透补偿，被图集流程抹糊的轮廓线重新收回笔锋状态。
[/list]

[h2]≡ 双边自适应锐化 ≡[/h2]
来自作者对 AMD CAS 锐化算法的改进开源算法 「BCAS」。
等同 CAS 的十字形 5 采样开销，实现离线工具级的双边锐化质量：
[list]
[*]YCoCg 色亮分离、MAD4 活动量估计、σ 自适应双边范围核、细节层压缩与软限幅、AURA 包络抗过冲、暗部保护、色度保护
[*]外加 8-bit 加固（TPDF 抖动 / 2LSB 底限 / 软底 EOTF）
[/list]
只锐游戏世界，HUD 不受影响，Lua 零每帧开销。

[h2]≡ 电影调色引擎 ≡[/h2]
曝光 EV / 白平衡光学色轮（HSV ↔ 色温色调解析映射）/ CDL 一级二级校正（ASC 原语）/ 高光去饱和 / ACES 胶片曲线混合（软底 EOTF）/ 原画混合，外加暗角与 8Hz 动态胶片颗粒。
[b]官方调色强度接管[/b]：复用官方季节/昼夜 LUT，0=原色 ~ 1=原版。

[h2]≡ 辉光管线接管（单 pass 架构）≡[/h2]
开启辉光时原生 Bloom 完全置空（无论引擎如何重开都被拦截），由本 Mod 全权替代：
[list]
[*][b]mip 金字塔[/b]：软膝高光提取（Unreal 二次曲线，只放真光源通过；软膝被钳到阈值，暗部永不被放大）→ 逐级 2x 盒式下采样（1/4 → 1/32），每级仅 4 抽头。
[*][b]合成[/b]：四级按权重画像叠加，SPREAD 在「紧凑热核 / 长柔尾」之间插值；暖色随层级渐染（核心保留光源本色）；保色软肩只压缩叠加过亮的亮度，不漂白颜色。
[*][b]架构[/b]：调色 + 锐化 + 辉光合成合并进【一个全分辨率 pass】（全屏渲染 2 次 → 1 次）；仅在异常显卡驱动下回退多 pass 链路。
[*]可选长尾呼吸 / 光包裹 / 轮廓光（默认关）。
[/list]
没有稀疏大步长采样，因此不存在方块与斜向拖影，也没有把整屏拖亮的假「光污染」。

[h2]≡ 海面波光 · 真实浅滩与深浅过渡 ≡[/h2]
叠加在原版水体之上的程序化波光层（不改原版海洋渲染）：
[list]
[*][b]程序化 caustics 光网[/b]：两层 chained caustics（宽网 + 细网）交叉；域扭曲把规则的六角网格揉成有机形状，再用大尺度 gate 成片抹除——光斑是散开的粼粼，不是连成一片的网。
[*][b]沙底质感[/b]：低频沙丘明暗 + 稀疏细沙颗粒，混成半透明青调，读作清浅的沙底浅水，而不是噪点。
[*][b]浅 → 深丝滑过渡[/b]：逐像素深度 = 离岸距离（引擎海水遮罩双环采样，昼夜无关）。浅滩金色通透；中海 caustics 沿风向各向异性拉长成长浪带、颜色转青；深海消退，交还原版青色与海浪。边界加噪声扰动，不生成硬线。
[*][b]黄昏加速 · 潮汐感[/b]：太阳越低，海面流动越快（以环境光作太阳高度驱动时间缩放），沙面反光随环境光自然退去——模拟退潮后浅滩露沙的观感。
[*][b]盐堆专属浅滩[/b]：盐堆（saltstack）本被简单粗暴地种在深海地块上；本 Mod 在其周围生成一块不规则浅滩——盐堆终于立在沙堆上。
[*][b]水陆遮罩 + 夜晚衰减[/b]：海洋纹理 alpha 判定水陆（陆地不亮），强度随环境光衰减。
[*][b]性能[/b]：面片叠加层（盐堆按簇合并为少量大面片 + 廉价分支），逐像素陆地早退；不重写原版海洋渲染。
[/list]

[h2]≡ 海洋地皮调色 ≡[/h2]
绿洲系通透青绿的海洋配色（8 地块含深浅分层与小地图配色），
世界生成时烘焙进海洋纹理，零额外渲染开销。

[h2]≡ 原版滤镜接管 ≡[/h2]
低SAN保色 / 失真消除 / 积雪上限 / 风沙遮罩过滤，四个实时开关，全部可逆。

[h2]≡ 画质工作室 ≡[/h2]
进世界按 Home 打开：7 页签 40+ 参数，拖动即实时预览，行尾 R 复位，
白平衡光学色轮取色，三套一键预设（[b]特调方案 / 轻量画质 / 电影胶片[/b]，同一基底不同强度）。
全部改动自动保存。

[h2]≡ 内置高清字体 ≡[/h2]
思源黑体（Source Han Sans）85px 视网膜重铸版：
非线性对比度强化 + 灰肩边缘去雾收敛，消除 41% 的半透明发灰边缘，
笔画收敛为刀刻纯白；9940 字符 100% 契合（SIL OFL 1.1）。
无需再订阅字体 Mod（字体 Mod 二选一）。

[h2]≡ 使用 ≡[/h2]
进世界后按 Home 打开画质工作室，预设选「[b]# 特调方案[/b]」即为作者实机调校的定版画质。
[b]热键[/b]：Home 开关面板 · PgDn 保存 · ESC 放弃 · P 开关滤镜。

[h2]≡ 性能与兼容 ≡[/h2]
纯客户端 Mod（client_only_mod），专用服务器零渲染开销；
与地图类 / 角色类 Mod 无冲突；不修改任何游戏文件。
