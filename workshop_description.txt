【BCAS Studio —— 饥荒联机版画质增强 · 全开源】

≡ 仓库位置（全开源）≡
GitHub: https://github.com/Nanmianyi/DST-BCAS-Studio
（含全部源码：GLSL 着色器、参数状态机、UI、构建工具链）
任何人都可以下载、学习、二次开发、借鉴，无需任何授权，作者没有任何意见。

≡ 这是什么 ≡
饥荒联机版第一个成功打通【全自定义后处理管线】的 Mod，
也是第一个真正具备实质性画质提升的 Mod——不只是调色，而是真正的画质修复与增强。

≡ 锐化：不是显卡滤镜那种锐化 ≡
本 Mod 的核心是一套双边自适应锐化管线（BCAS 算法）。
它和显卡自带锐化（NVIDIA/AMD 的驱动锐化、ReShade 的 CAS）有本质区别：
那些是单像素拉对比的"锐化滤镜"，而 BCAS 本质上是【用锐化完成的对图形资源的
高质量修复】——YCoCg 色亮分离、MAD4 活动量估计、σ 自适应双边范围核、
细节层压缩、软限幅、AURA 包络抗过冲、暗部保护，逐像素判定"该锐什么、
该保什么、该修什么"。同等画面占用下，效果远超 CAS。
双边锐化本来是 PS / 达芬奇这类软件里的离线处理算法，本 Mod 把它高质量地
轻量化、实时化进了饥荒引擎。

≡ 这意味着什么 ≡
全自定义后处理管线一旦打通，意味着 ReShade 里你能想到的超分算法、
锐化、色调映射、颗粒、暗角……理论上都可以用同样的方式接入饥荒。
本 Mod 就是这条路的先行验证：双 pass 实时管线（电影调色引擎 →
锐化与终合成），40+ 项参数全部游戏内实时可调、自动保存。

≡ 调色引擎 ≡
曝光 EV / 白平衡（体素无级调色轮取色）/ CDL 一级二级（斜率·偏移·幂，
ASC 决策清单标准）/ 高光去饱和 / ACES 胶片曲线（sRGB 软底 EOTF）/
饱和度·自然饱和度·对比度·亮度·Gamma / 8-bit 加固（2LSB 噪声底限 +
TPDF 亚像素抖动抗色带）。另有暗角、动态胶片颗粒（8Hz 闪动）、
原版昼夜滤镜开关、思源黑体高清字体（内置，无需再订阅字体 Mod）。

≡ 算法来源与开源声明 ≡
BCAS 的算法来自作者前些年自己编写、给自己在 ReShade 上使用的开源锐化
算法 "BCAS"（BCAS_Workspace V1.5）的移植与改进。项目全开源，
任何人都可以二次开发、借鉴、魔改——我没任何意见，玩得开心就好。

≡ 使用 ≡
进世界后按 Home 打开画质工作室，预设选「作者特调」即为作者实机调校的
发布画质；拖数值 / 点数值键入 / 行尾 R 复位，实时预览自动保存。
热键：Home 开关面板 · PgDn 保存 · ESC 放弃 · P 开关滤镜。
