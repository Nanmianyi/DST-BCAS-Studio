## 动态太阳光影（顶点斜投影 + 日晷 + 光束 + 物体受光）

| 能力 | 说明 |
| --- | --- |
| 日晷模型太阳 | 单一解析式输出影长/旋角/浓度/色温，全局共享（影子/受光面/光束/天光同源） |
| 顶点斜投影 | 接管引擎给每个动画实体多画的那一遍（`RENDERPASS.BLOOM`），顶点端沿太阳方向把几何斜投影到地面（`ground.xz = world.xz + world.y · dir / tan(el)`）；影长由**每个顶点自己的世界高度**决定，皮肤/骑乘/砍伐/生长/动画帧全由引擎当帧矩阵承担 |
| 结构性无摩尔纹 | 片元写覆盖度、bloom 缓冲 alpha 混合 ⇒ 覆盖度 1 直接替换前者 ⇒ 同一像素**永远只有一层** ⇒ 无过绘要压 ⇒ 不需要抖动 ⇒ 斜纹/摩尔纹/网点在数学上不可能出现 |
| 边缘柔和 | 影子边缘按覆盖度平滑过渡（半影落在合成端，浓度与影色一起给），贴根实、梢部化开，不是全局柔度旋钮 |
| 影色随光场 | 影子颜色取自**世界光照贴图**：夜里自然淡出、火把旁染色，不再是固定死黑 |
| 逆光 | 太阳或火光在物体背后时，**整面背光、只剩轮廓发光**（θ 编码同时携带左右与顺逆光分量） |
| 天亮/天黑 | 交叉淡变：模式切换点上浓度恰好为 0，天刚亮不显示、过几秒淡入（不再转圈或突然蹦出） |
| 夜间投影 | 方向**完全由附近光辉源判定**（火光在哪侧，影子朝反侧）；黄昏/黎明模式切换带滞回，不会转圈 |
| 全物体覆盖 | 不按 prefab 白名单：凡有 AnimState 且未被类别排除的施影者都参与（含玩家、生物、模组物件） |
| 方向零猜值 | 影子方向作为 uniform 直接进着色器，quad 真实世界轴从 MatrixW 读回 ⇒ 不再有"美术 +v 轴偏角"那类需要实机对齐的猜测 |
| 接收面门限 | 影子层固定在贴地高度，不会"爬"到树冠或角色身上 |
| 性能边界 | 对象池 + 屏幕矩形裁切；静态施影者睡眠（脏标记唤醒）；夜晚无光源零开销 |
| 太阳全局光 | 屏幕空间太阳位置驱动天光方向（SunFill） |
| 透云光束 | 光斑状态机 + 引擎光源勾边（保留） |
| 水面波光 | 温泉等水体引擎光源点缀（AttachWaterFX，保留） |

## 海面波光（bcas_glint.lua + shaders/bcas_glint.ksh）

| 能力 | 说明 |
| --- | --- |
| caustics 光网 | 单纯形噪声沙底底色 + chained caustics 锐化成光网；域扭曲打散规则网格、大尺度 gate 成片抹除，光斑呈散点粼粼 |
| 散乱化 | 域扭曲打散规则六角网格 + 大尺度 gate 成片抹除，光斑由"连成一片的网"变散点 |
| 浅→深过渡 | 逐像素深度 = 离岸距离（由引擎海水遮罩双环采样得出，昼夜无关）：浅滩金色通透，中海 caustics 拉长成长浪带，深海消退交还原版青色与海浪；边界加噪声扰动不生成硬边 |
| 盐堆浅滩补丁 | 镜头附近 saltstack 贪心聚类成 ≤6 块**大浅滩**（一个盐堆一块 quad 会重叠过绘卡顿），每块走廉价分支（跳过 fbm/离岸采样），补上科雷"盐堆种在深海地块"的科学漏洞 |
| 沙底质感 | 浅滩叠加低频沙丘明暗 + 细沙颗粒 + 定向沙纹，混成半透明青调——读作清浅的沙底浅水，不再是"脏水沟" |
| 遮罩/昼夜/档位 | 海洋纹理 alpha 判定水陆；环境光自动衰减（夜晚变暗）；modinfo 三档 + 面板 强度/增益/颗粒/融合；实体纯客户端（dedicated 零开销） |
