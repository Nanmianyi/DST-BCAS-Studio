[h2]≡ 动态全局光影（此前饥荒没有光影）≡[/h2]
原版世界没有太阳：角色脚下只有圆形黑斑，地上物与黑夜之间没有光影关系。本 Mod 从零补上：
[list]
[*][b]世界空间太阳[/b]：单一解析式输出影子长度/旋角/透明度/色温，晨长午短暮长，太阳第一次在饥荒里走完一天。
[*][b]剪影投影[/b]：角色与大型地物贴地剪影，与本体动画逐帧同步；皮肤/骑乘/换装/树木生长阶段全跟随，砍伐·燃烧·收割即时换形态；满月投影染月光蓝，雨雪衰减。
[*][b]性能[/b]：移动实体逐帧 / 静态地物距离分层帧预算 + 错峰种子；姿态量化、远处节流、夜晚与洞穴零开销门控。
[*][b]透云光束[/b]：云层开合状态机 + 引擎光源勾边。
[*][b]太阳全局光[/b]：太阳屏幕位置驱动天光方向。
[/list]

[h2]≡ 反卷积墨线修复 ≡[/h2]
图集合成 + 多级双线性缩放会把贴图低通抹糊。经典反卷积需估计逐帧变化的点扩散函数；这里模糊来源是确定量、核可参数化，于是「估计」退化为「求解」：边缘法向检测 + 双边门控核 + 暗部穿透补偿，在不产生白边光晕的前提下把手绘勾线笔锋收回来。

[h2]≡ 双边自适应锐化（BCAS）≡[/h2]
作者对 AMD CAS 的改进算法，5 采样开销实现离线级双边锐化：YCoCg 色亮分离、MAD4 活动量、σ 自适应双边核、细节压缩软限幅、AURA 抗过冲、暗部/色度保护，外加 8-bit 加固（TPDF 抖动 / 2LSB 底限）。只锐游戏世界，HUD 不受影响。

[h2]≡ 电影调色引擎 ≡[/h2]
曝光 EV / 白平衡光学色轮 / CDL 一二级 / 高光去饱和 / ACES 胶片曲线 / 原画混合，外加暗角与 8Hz 胶片颗粒；官方季节昼夜 LUT 强度可调（0=原色 ~ 1=原版）。

[h2]≡ 辉光管线接管（单 pass 架构）≡[/h2]
原生 Bloom 完全置空（引擎任何重开路径都被拦截），改由本 Mod 接管：
[list]
[*]软膝高光提取（膝钳到阈值，暗部不被放大）→ 逐级 2x 盒式下采样的 mip 金字塔（1/4→1/32，每级仅 4 抽头）→ 四级按权重画像合成（暖色随层级渐染、保色软肩压缩）。无稀疏大步长采样，因此没有方块/斜向拖影与整屏「光污染」。
[*]调色 + 锐化 + 辉光合成合并进【一个全分辨率 pass】（全屏渲染 2 次 → 1 次）。
[/list]

[h2]≡ 海面波光 · 真实浅滩与深浅过渡 ≡[/h2]
叠在原版水体之上的程序化波光层（不改原版海洋渲染）：
[list]
[*][b]散开式 caustics[/b]：两层 caustics 交叉，域扭曲揉散规则六角网格 + 大尺度 gate 成片抹除，光斑是散开的粼粼而非连成一片的网。
[*][b]沙底质感[/b]：低频沙丘明暗 + 稀疏细沙颗粒，混成半透明青调。
[*][b]浅→深丝滑过渡[/b]：逐像素深度=离岸距离（海洋遮罩双环采样，昼夜无关）；浅滩金色通透、中海拉长成长浪带、深海消退交还原版青色与海浪，边界加噪声不生成硬线。
[*][b]黄昏加速·潮汐感[/b]：太阳越低海面流动越快（环境光驱动时间缩放），沙面反光随之自然退去。
[*][b]盐堆专属浅滩[/b]：盐堆周围按簇生成不规则浅滩，让盐堆立在沙堆上。
[/list]
