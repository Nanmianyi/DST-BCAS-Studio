[h2]≡ 动态全局光影（此前饥荒没有光影）≡[/h2]
[list]
[*][b]世界空间太阳[/b]：解析式输出影长/旋角/透明度/色温，晨长午短暮长。
[*][b]纯色半透明剪影[/b]：无描边线、无重叠变深，多实体重叠也只落一笔；与本体动画逐帧同步，皮肤/骑乘/换装/树木阶段全跟随，砍伐·燃烧·收割即时换形态；满月染月光蓝。
[*][b]性能[/b]：移动逐帧 / 静态距离分层错峰；夜晚与洞穴零开销门控。
[*][b]透云光束 + 太阳全局光[/b]：云层开合状态机 + 引擎光源勾边，天光方向随太阳移动。
[/list]

[h2]≡ 反卷积墨线修复 ≡[/h2]
模糊来源是确定量（图集 + 多级双线性），于是「估计」退化为「求解」：边缘法向检测 + 双边门控核 + 暗部穿透补偿，收回手绘勾线笔锋且不产生白边。

[h2]≡ 双边自适应锐化（BCAS）≡[/h2]
对 AMD CAS 的改进算法：5 采样开销实现离线级双边锐化（色亮分离 + 活动量 + σ 自适应核 + AURA 抗过冲 + 暗部/色度保护）。只锐世界画面，HUD 不受影响。

[h2]≡ 电影调色引擎 ≡[/h2]
曝光 / 白平衡光学色轮 / CDL 一二级 / 高光去饱和 / ACES 胶片曲线 / 原画混合 + 暗角与胶片颗粒；官方季节昼夜 LUT 强度可调。

[h2]≡ 辉光管线接管（单 pass）≡[/h2]
原生 Bloom 完全托管：软膝高光提取 → 1/4~1/32 mip 金字塔（每级 4 抽头）→ 加权画像合成，无方块拖影与整屏光污染；调色+锐化+辉光合并为一个全分辨率 pass。

[h2]≡ 海面波光 · 浅滩与深浅过渡 ≡[/h2]
叠在原版水体之上的程序化波光（不改原版海洋渲染）：
[list]
[*][b]散开式 caustics[/b]：域扭曲揉散网格 + 大尺度 gate，光斑是散开的粼粼而非连成一片。
[*][b]沙底质感 + 浅→深丝滑过渡[/b]：逐像素离岸距离决定通透度，浅滩金色通透、深海交还原版青色，边界加噪声不出硬线。
[*][b]黄昏加速 · 盐堆浅滩[/b]：太阳越低海面流动越快；盐堆周围按簇生成不规则浅滩。
[/list]

[h2]≡ 海洋地皮调色 / 原版滤镜接管 ≡[/h2]
8 种海洋地块通透青绿配色（含深浅分层与小地图），世界生成时烘焙；低SAN保色、失真消除、积雪上限、风沙遮罩四个可逆开关。

[h2]≡ 画质工作室 ≡[/h2]
进世界按 Home：8 页签 60 项参数实时预览、行尾 R 复位、白平衡光学色轮、四套预设（特调方案 / 轻量画质 / 电影胶片 / 原版关闭），全部自动保存。面板字体固定用自带高清字体。

[h2]≡ 内置高清字体 ≡[/h2]
思源黑体 85px 视网膜重铸版（SIL OFL），去雾提锐、消除半透明发灰边缘；可自由开关，只影响游戏界面。

[h2]≡ 使用 / 性能 / 兼容 ≡[/h2]
Home 面板 · PgDn 保存 · ESC 放弃 · P 开关；预设选「特调方案」即作者定版画质。
纯客户端 Mod，专用服务器零渲染开销；与地图/角色类 Mod 无冲突；不改游戏文件。
