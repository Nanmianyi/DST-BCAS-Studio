# BCAS Studio —— 饥荒联机版画质增强（V6 光影引擎）

**保留《饥荒》原本的手绘美学，然后把它调到最好。**

BCAS Studio 是《饥荒：联机版》打通全自定义后处理管线的画质增强 Mod。
通过官方 Mod 着色器接口接入双 pass 实时渲染管线，锐化、墨线修复、
电影调色、辉光、动态太阳光影全部在游戏内实时完成。
40+ 参数实时可调、自动保存，性能开销与原版后处理相当。

> 💡 **全开源项目**：源码、GLSL 着色器、构建工具链全部开放，遵循 MIT 协议。

## 核心技术原理

### 一、动态全局光影 —— 此前，饥荒没有光影

原版《饥荒：联机版》里**不存在方向性光影**。角色脚下只有一个圆形黑斑，夜晚只有光源照明，地上的树、建筑、草丛与黑夜之间没有任何光影关系。时间在流逝，画面却永远静止。

BCAS Studio 从底层逻辑为世界补上这一层：

- **世界空间太阳（日晷模型）**：根据世界相位（清晨/正午/傍晚/深夜）、满月周期与季节天气，由单一解析函数精确推导太阳矢量。清晨影子长而淡，正午收短变实，傍晚再度拉长。
- **动态剪影投影系统**：角色、坐骑、树木、大型建筑挂载贴地剪影，与本体动画逐帧相位同步；砍伐、生长、骑乘即时变换形态；满月之夜倾泻冷色月光投影。
- **三级性能分层架构**：移动实体逐帧追踪，静态地物分层休眠与错峰打散，夜晚及洞穴零开销门控，满帧顺畅运行。
- **透云丁达尔光（God Rays）**：世界空间光斑配合云层开合状态机随机游走显隐，暖光抚过林间草木。

### 二、反卷积墨线修复（DECONV）

饥荒的美术资产经过图集合成和双线性采样后，手绘轮廓线的高频信息衰减严重。
通过定向边缘梯度检测，提取主法向并应用双边门控核反求解卷积扩散：
不产生传统锐化的白边光晕，精准将模糊漫射的边缘收束回原本的手绘笔触。

### 三、双边自适应锐化（BCAS 算法）

继承作者开源的双边自适应锐化技术：
- YCoCg 色亮分离，锐化严控于亮度通道，绝不产生彩色噪斑；
- MAD4 局部活动量估算自适应调整双边核半径；
- AURA 双通道软限幅包络，锁死过冲溢出上限，画质无损提锐。

### 四、电影调色与辉光重构

- **调色工作流**：曝光 EV → 白平衡光学色轮取色 → CDL 一级/二级斜率偏移幂 → ACES 胶片曲线高光滚落；
- **Kawase 四层柔光**：软膝预滤确保仅真光源泛光，配合光包裹（Light Wrap）让暖色光圈温润沁入周围阴影，消弭原生光源生硬边缘。
