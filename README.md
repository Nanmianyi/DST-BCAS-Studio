# 更好的光影与画质修复（BCAS Studio）

**保留《饥荒》原本的手绘美学，然后把它调到最好。**

《饥荒：联机版》的全自定义后处理管线画质增强模组：锐化、墨线修复、电影调色、辉光、
海面波光、动态太阳光影，全部在游戏内实时完成。调色 + 锐化 + 辉光合并进**单个全分辨率
pass**，8 个页签 60 项参数实时可调、自动保存。

纯客户端视觉模组：不改变任何游戏判定，联机时服务端无需安装。

> 全开源项目：源码、GLSL 着色器、ksh 构建工具链、离线验证脚本全部开放，MIT 协议。

## 使用

进世界后按 **Home** 呼出画质工作室：

| 操作 | 说明 |
| --- | --- |
| **Home** | 开关设置面板 |
| **P** | 滤镜总开关（一键对比原版/开启后） |
| **PgDn** | 保存并关闭面板 |
| **ESC** | 放弃本次改动 |
| 行尾 **R** | 单项复位（还原到该参数的基准值） |

预设一键切换：

- **# 特调方案** —— 作者实机逐项调校定版，开箱即用的最佳平衡；
- **# 轻量画质** —— 克制低调，只做基础通透与微锐化，适合低配或长时间游玩；
- **# 电影胶片** —— 强化对比与冷暖分离、带暗角与颗粒，适合截图与录视频；
- **# 原版关闭** —— 全部回到原版观感（用于对比）。

所有改动实时预览、自动保存，退出游戏也不会丢。

## 核心技术原理

> 完整实现细节与踩坑归档在各篇文档里（见下方「文档」），这里只讲思路。

### 一、影子剪影：为什么"没有描边线"

影子是实体美术的黑色副本，所以**美术本身就是问题**：部件边缘的 1~2px 半透明软边
叠到另一个部件的实心上，就会在半透明混合里加深成一条"黑色轮廓线"。

三步解决：

1. **硬 alpha 压平**：alpha ≥ 0.30 一律抬成实心（整块影子只剩一个浓度），
   软边像素直接丢弃而不是混合 —— 线的主因消失；
2. **逐部件深度错位**：把"美术高度 / 图集页 / 符号"编码成深度差，
   让每个部件在深度上稳定可分；
3. **单层混合**：每个影子配一个不可见的"写深度孪生体"（同 bank/build/动画/姿态），
   它先把每像素最近那层的深度写进缓冲，可见层再整体前推一点点 ——
   同一像素只有一个部件能通过深度测试，**每像素只混合一次**，重叠不再叠加变深。

多实体的影子叠在一起时会重新出问题（都贴在地面上，同一像素深度完全相同），
因此每个影子实体还带一个**整数深度档位**，档距大于"单实体内部错位总跨度"，
深度缓冲里只留覆盖该像素的最高档。

### 二、海面波光

一层跟随摄像机的贴地 quad：程序化法线 + 太阳镜面高光 + 焦散光网，叠加在原版水体
之上（**不重写原版海洋渲染**，可独立开关）。深浅过渡与沙底质感由海洋地皮调色和
波光层分层负责。

### 三、反卷积墨线修复

经典反卷积依赖逐帧变化的点扩散函数估计，而这里的模糊来源是确定量（图集压缩 +
双线性采样），因此可以直接构造反向滤波器，在线把轮廓线"重置"回清晰状态
（DECONV 强度可调，配 AURA 抗振铃约束）。

### 四、双边自适应锐化

CAS 只相当于固定的十字采样，遇到强边缘必然产生过冲；本模组把离线双边锐化的思路搬到
实时：色亮分离后在亮度上做活动量估计与 σ 自适应范围核，再经软限幅 + AURA 包络抗过冲 +
暗部与色度保护，等效提升清晰度而不产生可见振铃。

### 五、单 pass 后处理架构

调色、锐化、辉光合成合并进**一个全分辨率 pass**；辉光本身用 mip 金字塔
（1/4 → 1/32，每级 4 抽头）生成，长尾权重用加权画像合成。相比多 pass 链路，
带宽与状态切换开销显著更低。管线通过官方 Mod 着色器接口接入，不改动游戏本体文件。

## 性能

- 后处理合并为单 pass，开销与原版后处理相当甚至更省；
- 影子：移动实体逐帧追踪、静态地物按距离分层错峰 + 帧预算；夜晚与洞穴零开销门控；
- 静态剪影只在玩家附近挂载，远离即回收；写深度孪生体随影子一起创建/回收；
- 全部效果都可独立开关，低配可只留锐化 + 调色。
